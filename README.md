# MORZÉA™ V2 — THE REVEAL™

GitHub Pages-ready static luxury e-commerce preview.

## Originality rule
Competitor screenshots and competitor-owned product photographs are not included in this project. The preview uses original MORZÉA concept visuals and the V2 `THE VEIL CUT™` system.

## Features
- Three-product opening ritual
- English / Arabic with RTL
- Responsive mobile / tablet / desktop
- Product detail modal
- Cart drawer persisted in localStorage
- Origin Passport concept
- Calm Surface → Vivid Reveal color behavior
- No build step

## Deploy on GitHub Pages
Upload the **contents of this folder** to the root of `ex-experience/morzea` on `main`.
Then open: `Settings → Pages → Deploy from a branch → main / (root)`.
Expected URL: `https://ex-experience.github.io/morzea/`
